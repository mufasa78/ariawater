# TypeScript Configuration Fixes

## Issues Fixed

### 1. ari-water/tsconfig.json

**Problem:**
- Error: `Cannot find type definition file for 'vite/client'`
- TypeScript couldn't find Vite's client type definitions

**Solution:**
1. Removed `"vite/client"` from the `types` array in tsconfig.json
2. Created `src/vite-env.d.ts` file with a proper reference directive:
   ```typescript
   /// <reference types="vite/client" />
   ```

This is the standard Vite approach - Vite types are imported via a `.d.ts` file rather than in the tsconfig types array.

**Files Changed:**
- `artifacts/ari-water/tsconfig.json` - Removed `"vite/client"` from types
- `artifacts/ari-water/src/vite-env.d.ts` - Created new file with Vite reference

### 2. convex/tsconfig.json

**Problem:**
- Multiple errors: `Cannot write file 'd:/.../_generated/xxx.d.ts' because it would overwrite input file`
- The configuration was trying to emit TypeScript declarations to `_generated` folder
- But `_generated/**/*` was also in the `include` array
- This created a circular reference where TypeScript tried to compile generated files and emit to the same location

**Solution:**
Changed the configuration to use `noEmit: true` and removed declaration generation settings:

**Before:**
```json
{
  "compilerOptions": {
    "composite": true,
    "declaration": true,
    "declarationMap": true,
    "emitDeclarationOnly": true,
    "outDir": "_generated",
    // ...
  },
  "include": ["*.ts", "_generated/**/*"],
  "exclude": ["node_modules"]
}
```

**After:**
```json
{
  "compilerOptions": {
    "noEmit": true,
    // ... other options without declaration/emit settings
  },
  "include": ["*.ts"],
  "exclude": ["node_modules", "_generated"]
}
```

**Why This Works:**
- Convex CLI generates its own TypeScript definitions in `_generated/`
- The tsconfig is only needed for type-checking the source `.ts` files
- We don't need TypeScript to emit declarations since Convex handles that
- Excluding `_generated` prevents circular references

**Files Changed:**
- `convex/tsconfig.json` - Simplified configuration to focus on type-checking only

## Verification

Both configurations now:
- ✅ Have no circular references
- ✅ Properly resolve all type definitions
- ✅ Work with their respective build tools (Vite for frontend, Convex CLI for backend)
- ✅ Support TypeScript type-checking

## Additional Notes

### Vite Environment Variables
The `vite-env.d.ts` file also provides types for Vite's import.meta environment:
- `import.meta.env.VITE_*` - Environment variables
- `import.meta.hot` - HMR API
- `import.meta.glob()` - Glob imports

### Convex Generated Files
The `_generated/` folder contains:
- `api.d.ts` / `api.js` - API types and functions
- `server.d.ts` / `server.js` - Server-side utilities  
- `dataModel.d.ts` - Database schema types
- Individual function type definitions

These are auto-generated by `npx convex dev` or `npx convex deploy` and should not be manually edited.
